# راهنمای وصل کردن سرور ایران به جیمینای از طریق سرور خارج

## چرا؟
گوگل درخواست‌هایی را که از ایران به جیمینای می‌رسد رد می‌کند. برای همین سرور ایران از طریق یک «تونل» رمزشده
(SSH) به سرور خارج وصل می‌شود و سرور خارج درخواست را به گوگل می‌رساند.

```
ربات بله (سرور ایران) ──تونل رمزشده──► سرور خارج ──► جیمینای گوگل
```

## امنیت
- واسطه روی سرور خارج **فقط از داخل تونل** در دسترس است، نه از اینترنت؛ کس دیگری نمی‌تواند از آن استفاده کند.
- تونل با یک کاربر مخصوص به اسم `relay` ساخته می‌شود که **هیچ کاری جز همین تونل** نمی‌تواند بکند
  (نه دستور اجرا کند، نه فایلی ببیند، نه به جای دیگری وصل شود). این را تست کردیم.
- کلید جیمینای فقط روی سرور ایران (`~/.gemini_key`) است، نه روی سرور خارج، نه در GitHub.
- دیوار آتش سرور خارج روشن می‌شود و فقط درگاه SSH باز می‌ماند.

## خرید سرور خارج
- کشور: آلمان، هلند، فنلاند یا فرانسه (نه هنگ‌کنگ، روسیه یا چین؛ جیمینای آنجا هم بسته است).
- کوچک‌ترین سرور کافی است (۱ هسته، ۵۱۲ مگ یا ۱ گیگ رم).
- سیستم‌عامل: Ubuntu 22.04 یا 24.04.
- بعد از خرید این‌ها را دارید: **آی‌پی** سرور، **رمز root**، و گاهی **درگاه SSH** (اگر چیزی نگفتند، ۲۲ است).

## قدم‌ها (همه با کپی کردن دستور)

### قدم ۰: به‌روز کردن سرور ایران
روی سرور ایران:
```bash
~/quant/update.sh
```

### قدم ۱: ساختن کلید تونل (سرور ایران)
```bash
bash ~/quant/relay/iran_setup.sh key
```
یک خط طولانی چاپ می‌کند که با `bash foreign_setup.sh "ssh-ed25519 ...` شروع می‌شود. آن را نگه دارید.

### قدم ۲: فرستادن اسکریپت به سرور خارج (سرور ایران)
`IP` را با آی‌پی سرور خارج عوض کنید. رمز root سرور خارج را یک بار می‌پرسد:
```bash
scp ~/quant/relay/foreign_setup.sh root@IP:
```
(اگر درگاه SSH سرور خارج ۲۲ نیست: `scp -P درگاه ~/quant/relay/foreign_setup.sh root@IP:`)

### قدم ۳: آماده کردن سرور خارج
وارد سرور خارج شوید:
```bash
ssh root@IP
```
و همان خطی را که در قدم ۱ چاپ شد، کامل paste و اجرا کنید. در آخر باید `== Done.` ببینید.
بعد با `exit` از سرور خارج بیرون بیایید.

### قدم ۴: روشن کردن تونل (سرور ایران)
اگر هنوز کلید جیمینای را نگذاشته‌اید، اول:
```bash
nano ~/.gemini_key        # فقط کلید را paste کنید، ذخیره: Ctrl+O، خروج: Ctrl+X
chmod 600 ~/.gemini_key
```
بعد:
```bash
bash ~/quant/relay/iran_setup.sh connect IP
```
(اگر درگاه SSH سرور خارج ۲۲ نیست: `... connect IP درگاه`)

اگر آخرش نوشت `== Gemini works through the relay.` تمام است ✅

## قیمت جهانی طلا از همین تونل (ربات طلا و دلار)
ربات بله حالا قیمت طلا را از بازار جهانی (یاهو و gold-api) می‌گیرد، نه والکس. ممکن است این سایت‌ها از ایران باز نشوند؛
برای همین از همین تونل هم رد می‌شوند. اگر تونل را **قبلاً** ساخته‌اید، فقط یک بار این را روی **سرور خارج** بزنید:
```bash
ssh root@IP
bash foreign_setup.sh update
exit
```
(اگر فایل foreign_setup.sh روی سرور خارج قدیمی است، اول قدم ۲ را دوباره بزنید تا نسخه تازه کپی شود.)
باید برای هر دو مسیر `code 200` ببینید. بعد روی سرور ایران:
```bash
python3 ~/quant/global_gold.py
```
اگر قیمت‌ها را چاپ کرد، تمام است ✅

## دستورهای روزمره (سرور ایران)
| کار | دستور |
|---|---|
| تونل وصل است؟ | `systemctl status gemini-tunnel` |
| چرا وصل نمی‌شود؟ | `journalctl -u gemini-tunnel -n 30` |
| وصل کردن دوباره | `systemctl restart gemini-tunnel` |
| تست جیمینای | `bash ~/quant/relay/iran_setup.sh test` |

تونل با روشن شدن سرور خودش روشن می‌شود و اگر قطع شد، هر ۱۰ ثانیه دوباره تلاش می‌کند.
در زمان قطعی یا اختلال اینترنت بین‌الملل، تونل (و فقط بخش اخبار) کار نمی‌کند؛ بقیه ربات عادی کار می‌کند.

## اگر خطا داد
- `Permission denied (publickey)`: خط قدم ۱ کامل در قدم ۳ اجرا نشده. قدم ۱ و ۳ را دوباره بزنید.
- `location is not supported`: کشور سرور خارج هم برای جیمینای بسته است؛ سرور اروپایی بگیرید.
- `API key`: کلید در `~/.gemini_key` اشتباه است (فقط خود کلید، بدون فاصله یا متن اضافه).
