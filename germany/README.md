# راهنمای سرور آلمان (ربات تلگرام + متاتریدر + هوش مصنوعی)

## تصویر کلی
سرور آلمان کاملاً از سرور ایران جداست و هیچ ارتباطی با والکس ندارد.
```
┌────────────────────────────── سرور آلمان ──────────────────────────────┐
│                                                                       │
│  متاتریدر ۵ (با Wine) ──اکسپرت PriceBridge──► mt-bridge ──► فایل قیمت‌ها │
│     (سرویس mt5)          هر ۱۰ ثانیه           (127.0.0.1:8787)          │
│                                                     │                 │
│  تلگرام شما ◄──────────────────────────► telegram-bot ◄┘                 │
│                                            │  هر درخواست یک بار         │
│                                            └──► جیمینای (اخبار + جمع‌بندی) │
└───────────────────────────────────────────────────────────────────────┘
```
- همه قیمت‌ها (۲ دقیقه، لحظه‌ای، روزانه) از متاتریدر می‌آید.
- هر بار که دکمه‌ای زده شود (پیش‌بینی ۲ دقیقه، پیش‌بینی حدودی، گزارش، سیگنال)، ربات اول گزارش خودش را
  می‌سازد، بعد یک بار از جیمینای نظر می‌گیرد و هر دو را با هم می‌فرستد. نظر جیمینای با برچسب «آزمایشی» است
  و در پیش‌بینی ۲ دقیقه خودکار با قیمت واقعی سنجیده می‌شود (کارنامه‌اش در خود پیام می‌آید).
- ربات هیچ خرید و فروشی انجام نمی‌دهد؛ از متاتریدر فقط قیمت می‌خواند.

## مشخصات سروری که باید بخرید
| مورد | مقدار | چرا |
|---|---|---|
| کشور | آلمان (یا هلند/فنلاند) | جیمینای و تلگرام بدون تونل کار کنند |
| پردازنده | **x86_64 (اینتل/AMD)**، ۲ هسته | متاتریدر با Wine روی سرورهای ARM کار نمی‌کند (مثلاً سری CAX هتزنر **نه**) |
| رم | **حداقل ۲ گیگ** (۴ گیگ راحت‌تر) | متاتریدر + Wine حدود ۰٫۵ تا ۱ گیگ، ربات و لینوکس بقیه. با ۲ گیگ، setup.sh یک Swap چهار گیگی می‌سازد و نکته‌های «کم کردن مصرف رم» (قدم ۶) لازم است |
| دیسک | ۴۰ گیگ SSD یا بیشتر | Wine و متاتریدر و تاریخچه قیمت |
| سیستم‌عامل | **Ubuntu 24.04 LTS** | اسکریپت روی همین تست‌شده‌ترین است |
| آی‌پی | **IPv4** داشته باشد | بعضی کارگزارها و سرویس‌ها فقط IPv4 دارند |
| دسترسی | root با SSH | |

علاوه بر سرور لازم است:
1. **حساب متاتریدر ۵** نزد یک کارگزار که نماد طلا (XAUUSD یا GOLD) دارد. برای فقط قیمت گرفتن، **حساب دمو** کافی است.
2. **کلید جیمینای** (همان که دارید).
3. **ربات تلگرام** (در قدم ۳ با `@BotFather` می‌سازید).

## قدم‌ها

### قدم ۱: اجرای اسکریپت روی سرور
از کامپیوتر خودتان (PowerShell ویندوز) فایل را بفرستید و وارد سرور شوید. `IP` را با آی‌پی سرور عوض کنید:
```bash
scp setup.sh root@IP:      # فایل germany/setup.sh را قبلاً از GitHub دانلود کرده‌اید؛ در همان پوشه بزنید
ssh root@IP
bash setup.sh
```
- اگر مخزن GitHub خصوصی باشد، یک خط کلید چاپ می‌کند: GitHub → مخزن → Settings → Deploy keys → Add
  (تیک Allow write access **نه**)، بعد Enter.
- یک رمز برای کاربر `trader` (برای Remote Desktop) می‌پرسد. یک رمز قوی بدهید و یادداشت کنید.
- آخرش چند خط `OK`/`FAIL` می‌بینید. الان FAIL برای تلگرام، جیمینای و متاتریدر طبیعی است.

### قدم ۲: کلید جیمینای
```bash
nano ~/.gemini_key          # فقط کلید را paste کنید. ذخیره: Ctrl+O، خروج: Ctrl+X
chmod 600 ~/.gemini_key
python3 ~/quant/check_connections.py --news
```
جلوی Gemini باید `OK` باشد.

### قدم ۳: ربات تلگرام
1. در تلگرام به `@BotFather` پیام دهید، `/newbot`، یک اسم و یک نام کاربری (آخرش bot).
2. توکنی که می‌دهد را روی سرور بگذارید و اسکریپت را دوباره بزنید:
```bash
nano ~/.telegram_token
chmod 600 ~/.telegram_token
bash ~/quant/germany/setup.sh
```
3. به ربات خودتان در تلگرام پیام بدهید؛ شناسه‌تان را جواب می‌دهد. بعد:
```bash
echo "شناسه_شما" > ~/.telegram_allowed
```
از این به بعد مثل ربات بله: خط اول = صاحب ربات؛ آدم جدید با دکمه تأیید/رد اضافه می‌شود.

### قدم ۴: وصل شدن به میز کار سرور (Remote Desktop)
Remote Desktop از اینترنت بسته است (امن‌تر). از راه یک تونل رمزشده وصل می‌شوید:
1. روی کامپیوتر خودتان یک **PowerShell** باز کنید و بزنید (این پنجره را باز نگه دارید):
```
ssh -L 33389:127.0.0.1:3389 root@IP
```
2. برنامه **Remote Desktop Connection** ویندوز را باز کنید، در Computer بنویسید `localhost:33389`، Connect.
3. نام کاربری `trader` و رمزی که در قدم ۱ دادید.

### قدم ۵: نصب متاتریدر (داخل Remote Desktop)
از منوی Applications یک **Terminal** باز کنید و بزنید:
```bash
./mt5_install.sh
```
پنجره نصب متاتریدر باز می‌شود: Next ... Finish. در آخر اسکریپت آدرس و رمز اکسپرت را چاپ می‌کند؛ نگه دارید.

### قدم ۶: تنظیم متاتریدر (داخل Remote Desktop)
1. `File → Login to Trade Account`: با حساب کارگزارتان (دمو کافی است) وارد شوید. تیک **Save password** را بزنید.
2. `Tools → Options → Expert Advisors`: تیک **Allow algorithmic trading** و تیک **Allow WebRequest for listed URL**،
   و آدرس `http://127.0.0.1:8787` را اضافه کنید. OK.
   (اکسپرت ما معامله نمی‌کند؛ این تیک فقط برای اجرای اکسپرت لازم است.)
3. چارت طلا را باز کنید (`XAUUSD` یا `GOLD`، بسته به کارگزار).
4. در `Navigator` زیر `Expert Advisors`، `PriceBridge` را روی چارت بکشید. اگر نبود: راست‌کلیک → Refresh؛
   اگر باز نبود، F4 (MetaEditor) → فایل PriceBridge → F7 (Compile).
5. در پنجره `Inputs`: `Secret` = متنی که اسکریپت چاپ کرد. `ServerURL` همان `http://127.0.0.1:8787/mt/push` بماند. OK.
6. دکمه **Algo Trading** بالای متاتریدر سبز باشد. زبانه `Experts` پایین صفحه باید بنویسد:
   `PriceBridge: connected, sending XAUUSD every 10 s.`
7. **کم کردن مصرف رم** (برای سرور ۲ گیگی مهم است):
   - همه چارت‌ها جز همان چارت طلا را ببندید.
   - `Tools → Options → Charts`: عدد **Max bars in chart** را `5000` بگذارید.
   - `Tools → Options → Server`: تیک **Enable news** را بردارید.
   - در `Market Watch` راست‌کلیک → **Hide All** (فقط نماد طلا می‌ماند).
8. متاتریدر را با `File → Exit` ببندید (تا تنظیمات ذخیره شود) و از Remote Desktop بیرون بیایید (Log Out).

### قدم ۷: روشن کردن همیشگی متاتریدر
در پنجره SSH (به عنوان root):
```bash
systemctl enable --now mt5
python3 ~/quant/check_connections.py
```
بعد از حدود یک دقیقه جلوی `MetaTrader`، `MT daily` و `MT5` باید `OK` باشد. حالا متاتریدر بدون صفحه نمایش
و همیشه روشن است و با روشن شدن سرور خودش روشن می‌شود. در تلگرام همه دکمه‌ها کار می‌کنند.

## اگر رم کم آمد
- مصرف رم: `free -m` (ستون available اگر زیر ۲۰۰ بود، کم است).
- برنامه‌ها به ترتیب مصرف: `ps aux --sort=-rss | head -6`
- اگر رم پر شود، لینوکس **اول متاتریدر** را می‌بندد (ربات و گیرنده آخر از همه). متاتریدر بعد از ۳۰ ثانیه خودش
  دوباره روشن می‌شود؛ در آن فاصله دکمه‌های ربات می‌گویند قیمت تازه نیست.
- میز کار از راه دور (Remote Desktop) خودش حدود ۳۰۰ مگ رم می‌گیرد؛ فقط موقع تنظیم روشنش کنید و بعد Log Out کنید.
- اگر مرتب کم آمد، رم سرور را به ۴ گیگ ببرید (بیشتر شرکت‌ها بدون نصب دوباره ارتقا می‌دهند).

## اگر بعداً خواستید چیزی در متاتریدر عوض کنید
```bash
systemctl stop mt5          # اول متاتریدر همیشگی را خاموش کنید
```
بعد Remote Desktop (قدم ۴)، در Terminal: `WINEPREFIX=~/.mt5 wine ~/.mt5/drive_c/Program\ Files/MetaTrader\ 5/terminal64.exe &`،
تغییرات، `File → Exit`، Log Out، و:
```bash
systemctl start mt5
```

## دستورهای روزمره
| کار | دستور |
|---|---|
| همه چیز سالم است؟ | `python3 ~/quant/check_connections.py` |
| به‌روزرسانی کد | `~/quant/update.sh` |
| ربات تلگرام | `systemctl status telegram-bot` / `journalctl -u telegram-bot -n 30` |
| گیرنده قیمت | `systemctl status mt-bridge` / `journalctl -u mt-bridge -n 30` |
| متاتریدر | `systemctl status mt5` / `journalctl -u mt5 -n 30` |
| جواب‌های هوش مصنوعی | `tail -5 ~/quant/ai_log.csv` |

## تنظیمات اختیاری
- **کمیسیون کارگزار:** اگر حسابتان به جز فاصله خرید و فروش، کمیسیون هم دارد، درصد هر طرف را بنویسید
  (مثلاً ۰٫۰۰۵ درصد): `echo 0.005 > ~/.mt_fee` و `systemctl restart telegram-bot`. پیش‌فرض صفر است.
- **مدل جیمینای:** پیش‌فرض `gemini-2.5-flash`. برای عوض کردن: `echo "اسم-مدل" > ~/.gemini_model`.

## هزینه و سرعت هوش مصنوعی
- هر دکمه = یک درخواست به جیمینای با جستجوی گوگل. سهمیه رایگان جیمینای سقف روزانه دارد؛ بیشتر از آن پولی است.
  تعداد درخواست‌ها در `ai_log.csv` ثبت می‌شود.
- جواب معمولاً چند ثانیه طول می‌کشد (برای ۲ دقیقه حداکثر ۳۰ ثانیه صبر می‌کند؛ بعد بدون آن می‌فرستد).
- دو بار زدن پشت سر هم یک دکمه (کمتر از ۳۰ ثانیه) همان جواب قبلی را می‌گیرد تا هزینه دوبار نشود.

## امنیت
- کلیدها فقط روی سرور: `~/.telegram_token`، `~/.gemini_key`، `~/.mt_bridge_secret`. هرگز در GitHub یا چت.
- رمز حساب متاتریدر فقط داخل خود متاتریدر است.
- دیوار آتش فقط SSH را باز می‌گذارد. Remote Desktop و گیرنده قیمت فقط از داخل سرور (یا تونل SSH) در دسترس‌اند.
- کلید GitHub سرور «فقط خواندنی» است.
