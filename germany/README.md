# راهنمای راه‌اندازی سرور آلمان

## تصویر کلی
```
                         ┌──────────── سرور آلمان ─────────────┐
 تلگرام شما ◄──────────► │ telegram-bot  (همان ربات بله، روی تلگرام) │
                         │     │ دکمه «پیش‌بینی حدودی»              │
                         │     ├──► جیمینای (مستقیم، بدون تونل)      │
                         │     │     اخبار را می‌خواند و لحنش را     │
                         │     │     به عدد تبدیل می‌کند (🧪 آزمایشی) │
                         │     └──► mt_bars.csv / mt_tick.json     │
                         │ mt-bridge  (درگاه 8787) ◄────────────────┼── متاتریدر (اکسپرت PriceBridge)
                         └──────────────────────────────────────┘
```
- سرور آلمان به تلگرام و جیمینای **مستقیم** وصل می‌شود؛ تونل و سرور واسطه لازم نیست.
- ربات بله روی سرور ایران مثل قبل کار می‌کند. هر دو می‌توانند هم‌زمان روشن باشند.
- ربات هیچ خرید و فروشی انجام نمی‌دهد؛ از متاتریدر **فقط قیمت** می‌خواند.

## خرید سرور
- کشور: آلمان (یا هلند/فنلاند). سیستم‌عامل: **Ubuntu 22.04 یا 24.04**.
- اگر متاتریدر روی کامپیوتر خودتان (ویندوز) روشن است: کوچک‌ترین سرور کافی است (۱ هسته، ۱ گیگ رم).
- اگر می‌خواهید متاتریدر ۲۴ ساعته **روی همین سرور** باشد: حداقل ۲ هسته و ۴ گیگ رم
  (متاتریدر برنامه ویندوزی است و روی لینوکس با Wine سنگین است). راهنمایش: `metatrader/README.md`.

## قدم‌ها

### قدم ۱: فرستادن اسکریپت به سرور آلمان
از سرور ایران (که کد را دارد)؛ `IP` را با آی‌پی سرور آلمان عوض کنید:
```bash
scp ~/quant/germany/setup.sh root@IP:
```

### قدم ۲: اجرای اسکریپت روی سرور آلمان
```bash
ssh root@IP
bash setup.sh
```
- اگر مخزن GitHub خصوصی باشد، یک خط کلید چاپ می‌کند و می‌گوید آن را کجای GitHub بگذارید
  (Settings → Deploy keys، **بدون** تیک Allow write access). بعد Enter بزنید.
- در آخر چند خط `OK` / `FAIL` می‌بینید. الان FAIL برای تلگرام و جیمینای طبیعی است (هنوز کلیدی نگذاشته‌اید).
- سه خط آخر (آدرس و رمز متاتریدر) را نگه دارید؛ در قدم ۵ لازم است.

### قدم ۳: ساختن ربات تلگرام
1. در تلگرام به `@BotFather` پیام دهید، `/newbot` بزنید، یک اسم و یک نام کاربری (آخرش bot) بدهید.
2. یک «توکن» می‌دهد (شبیه `123456:ABC-...`). روی سرور آلمان:
```bash
nano ~/.telegram_token      # فقط توکن را paste کنید. ذخیره: Ctrl+O، خروج: Ctrl+X
chmod 600 ~/.telegram_token
bash ~/setup.sh
```
3. در تلگرام به ربات خودتان پیام بدهید. شناسه‌تان را جواب می‌دهد. آن را بگذارید:
```bash
echo "شناسه_شما" > ~/.telegram_allowed
```
از این به بعد مثل ربات بله: خط اول = صاحب ربات؛ آدم جدید با دکمه تأیید/رد اضافه می‌شود.

### قدم ۴: کلید جیمینای
```bash
nano ~/.gemini_key          # فقط کلید را paste کنید
chmod 600 ~/.gemini_key
python3 ~/quant/check_connections.py --news
```
اگر جلوی Gemini نوشت `OK` و لحن اخبار را نشان داد، تمام است.
- فایل `~/.gemini_base_url` **نباید** روی سرور آلمان باشد (فقط مال تونل سرور ایران است).
- اسم مدل پیش‌فرض `gemini-2.5-flash` است. اگر گوگل مدل تازه‌تری داد:
  `echo "اسم-مدل" > ~/.gemini_model`

### قدم ۵: وصل کردن متاتریدر
راهنمای کامل: `metatrader/README.md`.

## دستورهای روزمره (سرور آلمان)
| کار | دستور |
|---|---|
| همه چیز سالم است؟ | `python3 ~/quant/check_connections.py` |
| به‌روزرسانی کد | `~/quant/update.sh` |
| وضعیت ربات تلگرام | `systemctl status telegram-bot` |
| پیام‌های ربات | `journalctl -u telegram-bot -n 30` |
| وضعیت گیرنده متاتریدر | `systemctl status mt-bridge` |
| پیام‌های گیرنده | `journalctl -u mt-bridge -n 30` |

## چیزهایی که هنوز نمی‌دانیم (بعد از راه‌اندازی، check_connections.py جواب می‌دهد)
- **والکس از آلمان جواب می‌دهد؟** بعضی صرافی‌های ایرانی آی‌پی خارج را می‌بندند. اگر جلوی Wallex نوشت FAIL،
  دکمه‌های والکس (گزارش، سیگنال، پیش‌بینی‌ها) روی ربات تلگرام کار نمی‌کنند؛ ربات بله روی سرور ایران همچنان کار می‌کند.
  آن وقت باید تصمیم بگیریم پیش‌بینی‌ها روی قیمت متاتریدر (XAUUSD) ساخته شوند.
- تلگرام در ایران فیلتر است؛ استفاده از ربات تلگرام از داخل ایران فیلترشکن می‌خواهد.

## امنیت
- کلیدها فقط روی سرور، در فایل‌های `~/.telegram_token`، `~/.gemini_key`، `~/.mt_bridge_secret`. هرگز در GitHub یا چت.
- دیوار آتش فقط SSH و درگاه 8787 را باز می‌گذارد. گیرنده متاتریدر فقط بسته‌هایی را قبول می‌کند که با رمز مشترک امضا شده باشند.
- کلید GitHub سرور آلمان «فقط خواندنی» است.
