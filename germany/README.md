# راهنمای سرور آلمان (ربات تلگرام + هوش مصنوعی، متاتریدر اختیاری)

## خلاصه: نصب در ۳ قدم
سرور آلمان کاملاً از سرور ایران جداست و هیچ ارتباطی با والکس ندارد.
ربات تلگرام قیمت‌ها را مثل ربات بله **از بازار جهانی** می‌گیرد (Swissquote و یاهو؛ از آلمان مستقیم، بدون تونل و پروکسی).
متاتریدر **لازم نیست**؛ فقط اگر بعداً خواستید قیمت کارگزار خودتان را ببینید، بخش «اختیاری: متاتریدر» را بزنید.

| قدم | کار | کی تمام است؟ |
|---|---|---|
| ۱ | `bash setup.sh` روی سرور | آخرش جلوی `Gold USD` نوشته `OK` (FAIL برای Telegram و Gemini فعلاً طبیعی است) |
| ۲ | کلید جیمینای | جلوی `Gemini` نوشته `OK` |
| ۳ | ربات تلگرام | در تلگرام دکمه‌ها کار می‌کنند |

بعد از قدم ۳ کار نصب تمام است. یک تا دو هفته فقط استفاده کنید و هر ایده تازه را یادداشت کنید.
«پیش‌بینی ۲ دقیقه» تا حدود ۸۰ دقیقه بعد از روشن شدن ربات پیام «در حال جمع کردن» می‌دهد (ربات خودش کندل می‌سازد).

## تصویر کلی (با متاتریدر اختیاری)
```
┌────────────────────────────── سرور آلمان ──────────────────────────────┐
│                                                                       │
│  متاتریدر ۵ (با Wine) ──اکسپرت PriceBridge──► mt-bridge ──► فایل قیمت‌ها │
│     (سرویس mt5)          هر ۱۰ ثانیه           (127.0.0.1:8787)          │
│                                                     │                 │
│  تلگرام شما ◄──────────────────────────► telegram-bot ◄┘                 │
│                                            │  هر درخواست یک بار         │
│                                            └──► جیمینای (اخبار + جمع‌بندی) │
└───────────────────────────────────────────────────────────────────────┘
```
- بدون متاتریدر (پیش‌فرض): قیمت‌ها از بازار جهانی (global_gold.py)، مثل ربات بله.
- با متاتریدر (اختیاری): همه قیمت‌ها (۲ دقیقه، لحظه‌ای، روزانه) از متاتریدر می‌آید.
- هر بار که دکمه‌ای زده شود (پیش‌بینی ۲ دقیقه، پیش‌بینی حدودی، گزارش، سیگنال)، ربات اول گزارش خودش را
  می‌سازد، بعد یک بار از جیمینای نظر می‌گیرد و هر دو را با هم می‌فرستد. نظر جیمینای با برچسب «آزمایشی» است
  و در پیش‌بینی ۲ دقیقه خودکار با قیمت واقعی سنجیده می‌شود (کارنامه‌اش در خود پیام می‌آید).
- ربات هیچ خرید و فروشی انجام نمی‌دهد؛ از متاتریدر فقط قیمت می‌خواند.

## مشخصات سروری که باید بخرید
| مورد | مقدار | چرا |
|---|---|---|
| کشور | آلمان (یا هلند/فنلاند) | جیمینای و تلگرام بدون تونل کار کنند |
| پردازنده | ۱ هسته کافی است. **فقط برای متاتریدر:** x86_64 (اینتل/AMD)، ۲ هسته | متاتریدر با Wine روی سرورهای ARM کار نمی‌کند (مثلاً سری CAX هتزنر **نه**) |
| رم | ۱ گیگ کافی است. **فقط برای متاتریدر:** حداقل ۲ گیگ (۴ گیگ راحت‌تر) | متاتریدر + Wine حدود ۰٫۵ تا ۱ گیگ، ربات و لینوکس بقیه. با کمتر از ۳٫۵ گیگ، setup.sh یک Swap چهار گیگی می‌سازد |
| دیسک | ۴۰ گیگ SSD یا بیشتر | Wine و متاتریدر و تاریخچه قیمت |
| سیستم‌عامل | **Ubuntu 24.04 LTS** یا **22.04 LTS** | هر دو کار می‌کنند (کد ربات با کتابخانه‌های ۲۲.۰۴ هم تست شد). پشتیبانی امنیتی ۲۲.۰۴ تا آوریل ۲۰۲۷ و ۲۴.۰۴ تا ۲۰۲۹ است؛ اگر حق انتخاب دارید ۲۴.۰۴ |
| آی‌پی | **IPv4** داشته باشد | بعضی کارگزارها و سرویس‌ها فقط IPv4 دارند |
| دسترسی | root با SSH | |

علاوه بر سرور لازم است:
1. **کلید جیمینای** (همان که دارید).
2. **ربات تلگرام** (در قدم ۳ با `@BotFather` می‌سازید).
3. فقط برای متاتریدر: **حساب متاتریدر ۵** نزد یک کارگزار که نماد طلا (XAUUSD یا GOLD) دارد (**حساب دمو** کافی است).

## قدم‌ها

### قدم ۱: اجرای اسکریپت روی سرور
از کامپیوتر خودتان (PowerShell ویندوز) فایل را بفرستید و وارد سرور شوید. `IP` را با آی‌پی سرور عوض کنید:
```bash
scp setup.sh root@IP:      # فایل germany/setup.sh را قبلاً از GitHub دانلود کرده‌اید؛ در همان پوشه بزنید
ssh root@IP
bash setup.sh
```
- اگر مخزن GitHub خصوصی باشد، یک خط کلید چاپ می‌کند: GitHub → مخزن → Settings → Deploy keys → Add
  (تیک Allow write access **نه**)، بعد Enter.
- اگر وصل نشد (Connection timed out)، بخش «اگر از ایران به سرور وصل نشد» پایین همین صفحه.
- آخرش چند خط `OK`/`FAIL` می‌بینید. جلوی `Gold USD` باید `OK` باشد. FAIL برای تلگرام و جیمینای الان طبیعی است.

### قدم ۲: کلید جیمینای
```bash
nano ~/.gemini_key          # فقط کلید را paste کنید. ذخیره: Ctrl+O، خروج: Ctrl+X
chmod 600 ~/.gemini_key
python3 ~/quant/check_connections.py --news
```
جلوی Gemini باید `OK` باشد.

### قدم ۳: ربات تلگرام
1. در تلگرام به `@BotFather` پیام دهید، `/newbot`، یک اسم و یک نام کاربری (آخرش bot).
2. توکنی که می‌دهد را روی سرور بگذارید و اسکریپت را دوباره بزنید:
```bash
nano ~/.telegram_token
chmod 600 ~/.telegram_token
bash ~/quant/germany/setup.sh
```
3. به ربات خودتان در تلگرام پیام بدهید؛ شناسه‌تان را جواب می‌دهد. بعد:
```bash
echo "شناسه_شما" > ~/.telegram_allowed
```
از این به بعد مثل ربات بله: خط اول = صاحب ربات؛ آدم جدید با دکمه تأیید/رد اضافه می‌شود.

**نصب تمام شد.** آزمایش: در تلگرام «📡 سیگنال امروز» و «🔮 پیش‌بینی حدودی» را بزنید و `python3 ~/quant/check_connections.py`
همه `OK` باشد. (استفاده از تلگرام از داخل ایران فیلترشکن می‌خواهد.)

## اختیاری: متاتریدر (قدم‌های ۴ تا ۷)
فقط اگر بعد از چند هفته استفاده واقعاً لازم شد. کد ربات آماده است ولی Wine/متاتریدر و اکسپرت هنوز تست نشده‌اند.
اول در SSH:
```bash
bash ~/quant/germany/setup.sh --metatrader
```
Wine، میز کار سبک و Remote Desktop را نصب می‌کند (چند دقیقه) و یک رمز برای کاربر `trader` می‌پرسد (یادداشت کنید).
از این به بعد ربات تلگرام قیمت‌ها را از متاتریدر می‌خواند (تا متاتریدر روشن نشده، دکمه‌ها می‌گویند قیمت تازه نیست).

### قدم ۴: وصل شدن به میز کار سرور (Remote Desktop)
Remote Desktop از اینترنت بسته است (امن‌تر). از راه یک تونل رمزشده وصل می‌شوید:
1. روی کامپیوتر خودتان یک **PowerShell** باز کنید و بزنید (این پنجره را باز نگه دارید):
```
ssh -L 33389:127.0.0.1:3389 root@IP
```
2. برنامه **Remote Desktop Connection** ویندوز را باز کنید، در Computer بنویسید `localhost:33389`، Connect.
3. نام کاربری `trader` و رمزی که setup.sh --metatrader پرسید.

### قدم ۵: نصب متاتریدر (داخل Remote Desktop)
از منوی Applications یک **Terminal** باز کنید و بزنید:
```bash
./mt5_install.sh
```
پنجره نصب متاتریدر باز می‌شود: Next ... Finish. در آخر اسکریپت آدرس و رمز اکسپرت را چاپ می‌کند؛ نگه دارید.

### قدم ۶: تنظیم متاتریدر (داخل Remote Desktop)
1. `File → Login to Trade Account`: با حساب کارگزارتان (دمو کافی است) وارد شوید. تیک **Save password** را بزنید.
2. `Tools → Options → Expert Advisors`: تیک **Allow algorithmic trading** و تیک **Allow WebRequest for listed URL**،
   و آدرس `http://127.0.0.1:8787` را اضافه کنید. OK.
   (اکسپرت ما معامله نمی‌کند؛ این تیک فقط برای اجرای اکسپرت لازم است.)
3. چارت طلا را باز کنید (`XAUUSD` یا `GOLD`، بسته به کارگزار).
4. در `Navigator` زیر `Expert Advisors`، `PriceBridge` را روی چارت بکشید. اگر نبود: راست‌کلیک → Refresh؛
   اگر باز نبود، F4 (MetaEditor) → فایل PriceBridge → F7 (Compile).
5. در پنجره `Inputs`: `Secret` = متنی که اسکریپت چاپ کرد. `ServerURL` همان `http://127.0.0.1:8787/mt/push` بماند. OK.
6. دکمه **Algo Trading** بالای متاتریدر سبز باشد. زبانه `Experts` پایین صفحه باید بنویسد:
   `PriceBridge: connected, sending XAUUSD every 10 s.`
7. **کم کردن مصرف رم** (برای سرور ۲ گیگی مهم است):
   - همه چارت‌ها جز همان چارت طلا را ببندید.
   - `Tools → Options → Charts`: عدد **Max bars in chart** را `5000` بگذارید.
   - `Tools → Options → Server`: تیک **Enable news** را بردارید.
   - در `Market Watch` راست‌کلیک → **Hide All** (فقط نماد طلا می‌ماند).
8. متاتریدر را با `File → Exit` ببندید (تا تنظیمات ذخیره شود) و از Remote Desktop بیرون بیایید (Log Out).

### قدم ۷: روشن کردن همیشگی متاتریدر
در پنجره SSH (به عنوان root):
```bash
systemctl enable --now mt5
python3 ~/quant/check_connections.py
```
بعد از حدود یک دقیقه جلوی `MetaTrader`، `MT daily` و `MT5` باید `OK` باشد. حالا متاتریدر بدون صفحه نمایش
و همیشه روشن است و با روشن شدن سرور خودش روشن می‌شود. در تلگرام همه دکمه‌ها کار می‌کنند.

## اگر از ایران به سرور وصل نشد (Connection timed out)
«تایم‌اوت» یعنی درخواست شما اصلاً به سرور نرسیده و جوابی برنگشته. در ایران معمولاً یکی از این‌هاست:
فیلترینگ یا کندی اینترنت بین‌الملل روی SSH، بسته بودن درگاه ۲۲ به سمت آی‌پی‌های خارج، یا روشن نبودن خود سرور.
این آزمایش‌ها را به ترتیب انجام دهید تا علت معلوم شود:

**۱. سرور روشن است؟** در پنل شرکت سرور، وضعیت باید Running باشد. بیشتر شرکت‌ها یک **Console** (کنسول وب)
دارند که بدون SSH و از داخل سایت وارد سرور می‌شود (اگر سایت باز نشد با فیلترشکن). با root و رمزش وارد شوید.
اگر کنسول کار کرد، سرور سالم است و مشکل از راه ارتباطی است.

**۲. درگاه ۲۲ از خانه شما باز است؟** در PowerShell ویندوز:
```
Test-NetConnection IP -Port 22
```
اگر `TcpTestSucceeded : False` بود، راه بسته است.

**۳. با فیلترشکن امتحان کنید.** فیلترشکن را روشن کنید و دوباره `ssh root@IP`. اگر وصل شد، علت فیلترینگ ایران است
و یکی از راه‌های ۴ یا ۵ را بزنید (چون هر بار فیلترشکن روشن کردن برای کار با سرور دردسر دارد).

**۴. از راه سرور ایران.** سرورهای داخل دیتاسنتر معمولاً به خارج بهتر وصل می‌شوند (تونل جیمینای هم همین‌طور کار می‌کند).
روی سرور ایران امتحان کنید: `ssh root@IP_ALMAN`. اگر وصل شد، از کامپیوتر خودتان می‌توانید از روی سرور ایران «پل» بزنید:
```
ssh -J root@IP_IRAN root@IP_ALMAN
```
و برای Remote Desktop (قدم ۴):
```
ssh -J root@IP_IRAN -L 33389:127.0.0.1:3389 root@IP_ALMAN
```

**۵. باز کردن SSH روی درگاه ۴۴۳.** گاهی فقط درگاه ۲۲ به سمت خارج بسته است و ۴۴۳ (درگاه سایت‌ها) باز است.
از کنسول وب (آزمایش ۱) این‌ها را بزنید؛ SSH روی هر دو درگاه ۲۲ و ۴۴۳ گوش می‌دهد:
```bash
mkdir -p /etc/systemd/system/ssh.socket.d
printf '[Socket]\nListenStream=\nListenStream=22\nListenStream=443\n' > /etc/systemd/system/ssh.socket.d/port.conf
systemctl daemon-reload
systemctl restart ssh.socket
ufw status | grep -q active && ufw allow 443/tcp
```
بعد از کامپیوتر خودتان: `ssh -p 443 root@IP` (و برای فرستادن فایل: `scp -P 443 setup.sh root@IP:`).
setup.sh درگاه‌های SSH را خودش پیدا می‌کند و هر دو را در دیوار آتش باز نگه می‌دارد.
برای Remote Desktop هم: `ssh -p 443 -L 33389:127.0.0.1:3389 root@IP`

نکته: در روزهای اختلال یا قطعی اینترنت بین‌الملل هیچ‌کدام کار نمی‌کند؛ ولی ربات روی سرور آلمان کارش را ادامه می‌دهد.
استفاده از ربات تلگرام از داخل ایران هم (چون تلگرام فیلتر است) فیلترشکن می‌خواهد.

## اگر رم کم آمد
- مصرف رم: `free -m` (ستون available اگر زیر ۲۰۰ بود، کم است).
- برنامه‌ها به ترتیب مصرف: `ps aux --sort=-rss | head -6`
- اگر رم پر شود، لینوکس **اول متاتریدر** را می‌بندد (ربات و گیرنده آخر از همه). متاتریدر بعد از ۳۰ ثانیه خودش
  دوباره روشن می‌شود؛ در آن فاصله دکمه‌های ربات می‌گویند قیمت تازه نیست.
- میز کار از راه دور (Remote Desktop) خودش حدود ۳۰۰ مگ رم می‌گیرد؛ فقط موقع تنظیم روشنش کنید و بعد Log Out کنید.
- اگر مرتب کم آمد، رم سرور را به ۴ گیگ ببرید (بیشتر شرکت‌ها بدون نصب دوباره ارتقا می‌دهند).

## اگر بعداً خواستید چیزی در متاتریدر عوض کنید
```bash
systemctl stop mt5          # اول متاتریدر همیشگی را خاموش کنید
```
بعد Remote Desktop (قدم ۴)، در Terminal: `WINEPREFIX=~/.mt5 wine ~/.mt5/drive_c/Program\ Files/MetaTrader\ 5/terminal64.exe &`،
تغییرات، `File → Exit`، Log Out، و:
```bash
systemctl start mt5
```

## دستورهای روزمره
| کار | دستور |
|---|---|
| همه چیز سالم است؟ | `python3 ~/quant/check_connections.py` |
| به‌روزرسانی کد | `~/quant/update.sh` |
| ربات تلگرام | `systemctl status telegram-bot` / `journalctl -u telegram-bot -n 30` |
| گیرنده قیمت (فقط با متاتریدر) | `systemctl status mt-bridge` / `journalctl -u mt-bridge -n 30` |
| متاتریدر (فقط با متاتریدر) | `systemctl status mt5` / `journalctl -u mt5 -n 30` |
| جواب‌های هوش مصنوعی | `tail -5 ~/quant/global/ai_log.csv` (با متاتریدر: `~/quant/ai_log.csv`) |

## تنظیمات اختیاری
- **کارمزد (بدون متاتریدر):** درصد هر طرف کارگزارتان: `echo 0.005 > ~/.global_fee` و `systemctl restart telegram-bot`. پیش‌فرض صفر.
- **کمیسیون کارگزار (با متاتریدر):** اگر حسابتان به جز فاصله خرید و فروش، کمیسیون هم دارد، درصد هر طرف را بنویسید
  (مثلاً ۰٫۰۰۵ درصد): `echo 0.005 > ~/.mt_fee` و `systemctl restart telegram-bot`. پیش‌فرض صفر است.
- **مدل جیمینای:** پیش‌فرض `gemini-2.5-flash`. برای عوض کردن: `echo "اسم-مدل" > ~/.gemini_model`.

## هزینه و سرعت هوش مصنوعی
- هر دکمه = یک درخواست به جیمینای با جستجوی گوگل. سهمیه رایگان جیمینای سقف روزانه دارد؛ بیشتر از آن پولی است.
  تعداد درخواست‌ها در `ai_log.csv` ثبت می‌شود.
- جواب معمولاً چند ثانیه طول می‌کشد (برای ۲ دقیقه حداکثر ۳۰ ثانیه صبر می‌کند؛ بعد بدون آن می‌فرستد).
- دو بار زدن پشت سر هم یک دکمه (کمتر از ۳۰ ثانیه) همان جواب قبلی را می‌گیرد تا هزینه دوبار نشود.

## امنیت
- کلیدها فقط روی سرور: `~/.telegram_token`، `~/.gemini_key` (و با متاتریدر `~/.mt_bridge_secret`). هرگز در GitHub یا چت.
- رمز حساب متاتریدر فقط داخل خود متاتریدر است.
- دیوار آتش فقط SSH را باز می‌گذارد. Remote Desktop و گیرنده قیمت فقط از داخل سرور (یا تونل SSH) در دسترس‌اند.
- کلید GitHub سرور «فقط خواندنی» است.
